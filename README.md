# IRIT_Order-Tracking
IRIT_Order-Tracking — консольное приложение для управления заказами канцелярии. Проект предназначен для автоматизации основных процессов работы с заявками и отчётностью. Приложение позволяет регистрировать пользователей, редактировать и просматривать каталог канцтоваров, создавать и отслеживать заказы.
# Возможности
В проекте реализованы следующие основные возможности:
* Регистрация пользователей.
* Авторизация пользователей.
* Просмотр каталога.
* Управление каталогом.
* Создание заявок в канцелярию.
* Отслеживание статуса заявок.
* Обработка заявок.
* Управление остатками на складе.
